Overview

Engineering automation with explicit design stages.

PE-Claw 1.0 is organized around a deterministic GUI/backend flow. Each stage exposes concrete electrical models, design decisions, selected hardware, and result artifacts instead of hiding the workflow behind a black-box optimizer.

K

Knowledge Library

Topology equations, waveform and stress models, device and passive design knowledge, loss models, thermal models, and engineering constraints.

R

Rule Library

Requirement handling, topology-specific synthesis, component filtering, Pareto ranking, staged execution, and reporting rules.

D

Device Library

Semiconductors, capacitors, magnetic cores, winding options, package geometry, thermal data, and mechanical attributes used by the design engines.

Current release boundary. PE-Claw 1.0 accepts structured GUI inputs and runs a deterministic engineering workflow. AI design, agentic execution, natural-language design intake, and autonomous design loops are future-product directions and are not presented here as implemented 1.0 capabilities.
Workflow

From converter specification to fixed-hardware analysis.

01

Select topology

Choose AC-DC, DC-AC, or DC-DC and enter topology-specific operating requirements.

02

Run Design

Perform electrical synthesis, generate waveforms, extract device stress, select semiconductors, and create the first design report.

03

Run Capacitor

Evaluate ripple and ESR constraints, build capacitor banks, generate Pareto fronts, and select a representative design.

04

Run Magnetics

Search core and winding candidates, screen saturation and loss, compress the design space, and generate geometry artifacts.

05

Refresh operating point

Regenerate waveforms and losses with the already selected hardware without silently re-optimizing the design.

06

Efficiency Sweep

Evaluate fixed selected hardware across 0.1–1.0 p.u. load and report efficiency and loss breakdown.

Capabilities

One design report, multiple engineering views.

The GUI organizes the same underlying design into complementary views for electrical behavior, selected hardware, optimization tradeoffs, losses, thermal constraints, efficiency, and geometry.

Electrical synthesis

Duty ratio, component sizing, operating mode, ripple targets, and topology-specific nominal design calculations.

Waveform & stress extraction

Switching-period waveforms and voltage/current stress passed directly into downstream component-selection stages.

Semiconductor selection

Library filtering with role, rating, manufacturer, loss, and thermal considerations.

Capacitor Pareto design

Voltage, capacitance, ripple-current, ESR-loss, thermal-proxy, volume, and bank-configuration tradeoffs.

Magnetic design

Core/winding search, saturation screening, core and copper loss, thermal proxy, Pareto compression, and geometry generation.

Loss & thermal analysis

Selected-hardware loss aggregation with first-pass thermal assessment across active and passive components.

Efficiency sweep

Fixed-hardware load sweep with efficiency curve, stacked loss breakdown, peak-efficiency summary, and dominant-loss reporting.

2D / 3D engineering visualization

Component geometry and hardware overview artifacts for design inspection and communication.

Supported topologies

Software architecture

Eight layers from GUI state to engineering output.

The repository separates topology physics, orchestration, libraries, multi-physics engines, shared models, and result visualization so each stage can be inspected and evolved independently.

Get started

Run PE-Claw locally.

PE-Claw 1.0 requires Python 3.10 or newer. Install the package from the repository root, then launch the GUI.

Install
python -m pip install -e .
Launch
python -m pe_claw_gui
